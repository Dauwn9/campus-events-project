# AIU Campus Events — обновлённый дизайн

Редизайн существующего проекта из архива campus-events-project (1).rar.

## Что изменено

- Глубокий синий фон шапки и баннера, золотистые акценты, приглушённый серо-голубой фон страницы.
- Логотип AIU и официальная иллюстрация кампуса, сохранённые в public/images.
- Ссылки на https://aiu.kz/?lang=ru и студенческую жизнь https://aiu.kz/life-at-aiu?lang=ru.
- Главная страница: большой баннер, тематические обложки событий, ближайшие встречи, блок об университете, нижний баннер и подвал.
- Работающие поиск по названию, описанию и месту, категории, фильтр дат, переключение сетка/список и сброс фильтров.
- Оформление страницы события, единая шапка для существующих ролей.
- Адаптивная компоновка. Изображения не зависят от доступности сайта AIU при просмотре.
- Компактный переключатель демонстрационных ролей. Раскройте его в правом нижнем углу.

## Запуск в Windows

Распакуйте ZIP в отдельную папку, например E:\campus-events-aiu. Откройте cmd.exe и перейдите в папку с package.json:

```cmd
cd /d "E:\campus-events-aiu\campus-events-project"
npm ci
npm run dev
```

Откройте адрес, который напечатает Next.js, обычно http://localhost:3000.

Для production-проверки:

```cmd
npm run build
npm start
```

Проект работает в локальном демонстрационном режиме. Добавлены рабочие серверные операции и локальная регистрация/авторизация. Все разделы используют одно хранилище .data/campus-demo.json: изменения сохраняются между переходами и перезапусками. PostgreSQL для просмотра демо не требуется. Установка npm ci требует доступа к npm; первая сборка может загружать шрифт Inter через next/font.

Демонстрационные аккаунты (общий пароль Campus2026!): student@demo.aiu.kz, organizer2@demo.aiu.kz, admin@demo.aiu.kz. Можно зарегистрировать собственного студента через /register. Переключатель демо-ролей остаётся внизу справа; он предназначен для локальной проверки. Три базовых демо-аккаунта защищены от изменения роли и блокировки, остальные пользователи управляются через админ-панель.

Файловое хранилище рассчитано на один локальный процесс Next.js. Это не подключение к производственной PostgreSQL и не готовый многосерверный сервис. NEXT_PUBLIC_USE_MOCKS=false требует отдельной реализации реальных сервисов. Runtime-файл содержит сессии, хеши паролей и ключ подписи QR: он не публикуется и не входит в ZIP.

В архив не включены node_modules, .next, .git, .data, временная папка work и локальные секреты. Prisma Client создаётся автоматически при npm run build.

## Возможности ролей

| Роль | Рабочие разделы |
| --- | --- |
| Гость | Афиша, поиск и фильтры, страницы событий, регистрация и вход. |
| Студент | Запись и отмена, лист ожидания, QR-билет и короткий код, история посещений, избранное, комментарии, профиль и смена пароля. |
| Организатор | Свои события и статусы, создание/редактирование, черновик и отправка на модерацию, отмена/удаление, участники и CSV, камера/изображение/ручной код для контроля входа. |
| Администратор | Обзор, одобрение/отказ с причиной, история решений, категории, поиск пользователей и изменение ролей/блокировки, удаление комментариев. |

Полный сценарий: организатор создаёт событие → администратор одобряет → событие появляется в афише → студент записывается → получает QR в «Моих регистрациях» → организатор проверяет билет в сканере. Вход открыт за час до начала и до окончания события. Повторный билет показывает первую отметку и не увеличивает посещаемость. Камера включается по кнопке и требует разрешения браузера; ручной ввод и чтение изображения доступны отдельно.

Пока событие на модерации, его видят только владелец и администратор. Изменение опубликованного события возвращает его на проверку. Вместимость нельзя уменьшить ниже числа записей. Когда мест нет, новая запись попадает в очередь; при отмене подтверждённой записи первый ожидающий получает место и QR. Приоритетное окно записи доступно участникам с тремя подтверждёнными посещениями.

Время событий отображается по часовому поясу Астаны (Asia/Qyzylorda). Исходные даты и записи событий сохранены. Прошедшие события отмечены в карточках и не попадают в список ближайших встреч.

## Проверка

Проверено: npm run build с TypeScript и Prisma generation; публичная афиша; создание и модерация события в браузере; регистрация, избранное и комментарий; QR-билет; успешный и повторный ручной check-in; создание аккаунта, повторный вход, профиль; отказ студенту в кабинете организатора; назначение роли пользователю. Автоматические сценарии запускаются командой npm test, включая декодирование настоящего PNG QR обратно в подписанный токен. Мобильные кабинеты проверены на ширине 390 px. Подробности — ROLE-FUNCTIONALITY-REPORT.md. Физическая камера не тестировалась: её доступ требует действия владельца устройства; QR-декодер и ручной вход проверены.

## Основные файлы дизайна

- src/app/globals.css — цвета, компоненты и адаптивные состояния.
- src/components/events/EventDiscovery.tsx — главная страница и фильтры.
- src/components/events/EventPoster.tsx, src/lib/event-design.ts — обложки событий.
- src/components/layout/Header.tsx, HeaderNav.tsx, Footer.tsx — навигация и подвал.
- public/images/aiu-logo.svg, aiu-campus.webp — материалы официального сайта AIU.

Дизайн связан с AIU визуально и ссылками; это учебный Campus Events проект, а не заявление об официальном статусе сервиса.
